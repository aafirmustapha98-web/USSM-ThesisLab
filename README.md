# USSM-ThesisLab

**Build. Challenge. Learn.**

Application de travail personnelle pour l'analyse des actions américaines.
Les données macro (Trading Economics) et financières (Finviz) sont collectées à la main.
L'application structure l'analyse, force l'interprétation, contrôle les trous de raisonnement
et challenge la thèse — **elle ne prend jamais la décision.**

> L'IA ne remplace jamais le raisonnement. Elle en augmente la qualité.
